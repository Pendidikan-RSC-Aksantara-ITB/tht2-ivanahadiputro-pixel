Jelaskan apa itu SPA (Single Page Application) dan bagaimana SPA berbeda dari aplikasi web tradisional? Sebutkan juga beberapa keuntungan dan kerugian menggunakan SPA dalam pengembangan web.


Jawaban:
_Single Page Application_ merupakan merupakan sebuah tipe aplikasi web yang menampilkan informasi atau konten dengan data baru secara dinamis dan interaktif terhadap user, hal ini terjadi karena pemanfaatan Javascript dalam pemanggilan data-data penting dari server dalam format JSON (_Javascript Object Notation_). Perbedaan utama SPA dengan aplikasi web tradisional adalah SPA menghindar adanya satu web untuk _reload_ sehingga _user experience_ berjalan secara lebih optimal.

Keunggulan:
- Kemampuan user untuk pindah-pindah menu untuk menampilkan informasi sangat cepat dikarenakannya satu web tidak perlu _reload_ untuk menampilkan halaman baru
- Karena server tidak perlu _render_ tiap halaman berkali-kali, maka beban server yang dihasilkan rendah sehingga _bandwidth_ yang digunakan relatif kecil
- SPA mengakibatkan penampilan aplikasi web yang interaktif, sehimgga cocok digunakan untuk _dashboard_ dan juga _interface_ yang lebih dinamis, seperti GCS

Kerugian:
- Karena SPA tidak me-reload tiap kali user buka menu, maka pemuatan halaman dasar pertama bersama dengan Javascript akan mengakibatkan waktu _loading_ yang pertama cukup lama dibandingkan dengan aplikasi web biasa
- Karena sifatnya yang berhalaman tunggl (single page), maka total data yang bisa ditempatkan pada halaman tersebut cukup terbatas
